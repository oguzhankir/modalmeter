# Examples

M0 provides a runnable foundation quickstart in the root README and a
[labeled feasibility probe](../docs/evidence/m0/README.md). No inspector, report,
comparison or endpoint example exists yet. Add examples only alongside the
feature they actually exercise.

The [golden evidence fixture](../tests/fixtures/evidence-v1.json) was authored for
this project under MIT and represents unavailable data. The probe's synthetic
solid-color frames are generated in code under MIT; the temporary video is not
tracked. Later examples must record their synthetic generator or public media
license/source and preserve attribution. Private owner media is not publishable
without explicit authorization.
